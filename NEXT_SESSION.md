# Промпт следующей сессии

Ты продолжаешь работу над **Skeleton** — браузерной песочницей в духе Valheim про скелета и мёртвую воду.
Репозиторий: `/home/itiro/dev/games/skeleton`. Ветка `main`, **ничего не закоммичено** — так и оставь, пока
не попросят. PR не создавай.

## Стек и команды

- TypeScript, npm workspaces, three.js `WebGPURenderer` (WebGL2 fallback), Vite, Vitest.
- `npm run dev` — клиент на http://localhost:5173 (одиночная игра, сервер не нужен).
- `npm run typecheck && npm test` — перед любым коммитом; сейчас зелёные (59 тестов).
- `npm run bench:aio` — замер на эталоне (aio, GTX 860M). По умолчанию мерит пиксельный вид;
  `--pixels 0` — полное разрешение (новый дефолт игры).
- `P` — пиксель-вид вкл/выкл, `?pixels=0/1` — то же в URL, `?vision=0` — серый старт, `?seed=42` — мир.

## Что уже сделано в этой сессии

- **Деревья.** Три вида (`spruce`, `birch`, `dead`) в `packages/client/src/world/trees.ts`; у ели и берёзы
  по два варианта силуэта. Геометрия слита в одну на вариант, цвет вершин, неоднородный масштаб
  (`composeInstance(..., scaleXZ, scaleY)` в `instanced-pool.ts`), ветер через `positionNode` (TSL).
  Пять глобальных пулов в `chunks.ts`, ближний префикс теней считается по каждому пулу.
- **Трава.** В `grass.ts` каждая травинка в пучке со своей высотой/шириной/наклоном/шагом.
  Матрицы разброса не трогали — золотой тест `packages/shared/tests/scatter.test.ts` цел.
- **Пиксель-вид выключен по умолчанию.** `renderer.ts`: `pixels = false`, `setPixels(on)`, `P` включает.
  Полное разрешение дало 284 fps на 860M (p95 1.6 мс), пиксель — 366 fps.
- **Документация графики и восприятия.** `docs/graphics.md` (направление, палитра, детализация, свет/туман,
  прозрение), `docs/systems.md` (восприятие, первые полчаса), `docs/music.md` (музыка), `docs/characters.md`
  (голос Повитухи), `GLOSSARY.md` (тело, мера, восприятие), `docs/adr/0001`, `docs/adr/0002`,
  `docs/specs/body-in-sim.md`.
- **Графические проходы 1–6** (`docs/graphics.md` «Порядок работ»): палитра/земля (`shared/src/ground-color.ts`),
  пропы Погоста (`shared/src/terrain.ts` `propsInChunk` + `client/src/world/props.ts`), туман по биомам и низкий
  слой, свет (предрассвет 05:00), частичный «первый кадр» (интро-камера + серый старт + нить-заглушка
  `client/src/render/nit.ts`). Проход 2 (деревья LOD) — условный, пропущен. Прозрение и аудио — не сделаны.

## Решения, которые нельзя потерять

- **Эстетика — северная сказка**, не яркий луг: туман, приглушённые цвета, мокро и мшисто, маленькая фигура
  в большом мире. Норштейн — настроение, Билибин — силуэт, север — материал. Пиксель — опция, не стиль.
- **Цвет — география.** Центр (Погост) серый, кольца прибавляют жизнь. Палитра Погоста и три зелёных —
  в `docs/graphics.md`, раздел «Палитра».
- **Деталь — след, а не украшение.** Вблизи 1–2 пропа на 100 м², вдали ноль. В срез идут курганы, кресты,
  кости; ограды, дары, пни — после.
- **Свет:** предрассветный туман, старт около 05:00 (`START_TIME` в `environment.ts` пока 0.3 = 07:12 —
  это правится в следующем проходе), низкое солнце, длинные тени, туман слоями по биомам.
- **Прозрение:** первый цветной кадр — лицо Повитухи, наполовину кость, наполовину плоть, в свете огня;
  цвет заливает весь кадр сразу, било бьёт в тот же момент.
- **Навь:** не второй мир. С плотью — слой поверх Яви; без плоти Явь уходит в холодный полутон и тише.
- **Восприятие:** мир — через тело (без глаз ночь светлая, без ушей звук под водой); иномирные голоса
  (Повитуха, мёртвые, духи) — в голову, мимо ушей; партитура играет всегда. Это ADR-0002.
- **Тело:** сущность мира, части — один список, орган/ткань, нить — мера. ADR-0001 и `docs/specs/body-in-sim.md`.
  В коде ещё не реализовано.

## Грабли

- **Не менять матрицы разброса травы** без обновления золотых хешей в `packages/shared/tests/scatter.test.ts`.
  Форму травинки меняй в `tuftGeometry` — это клиентская геометрия, хеши не трогает.
- **Пиксель-вид** — опция. Не включай по умолчанию без просьбы. При включении всё зернистое:
  `PIXEL_SCALE=0.5` + `image-rendering: pixelated` + `antialias: false`.
- **aio глазами:** собери клиент, скопируй `packages/client/dist` на aio, подними `python3 -m http.server`,
  а Chrome запускай под `prime-run` как X11-приложение: `--ozone-platform=x11 --use-gl=angle --use-angle=gl`.
  Без этого Wayland/Vulkan падает с EGLImage.
- **Тени деревьев не качаются** — depth pass не получает `positionNode`. Пока считается нормой.
- **Музыка, словарь, ADR и спека — untracked.** Не потеряй их при уборке.
