# Документация

Раздел «Основа» в `pitch.md` утверждён. Остальное — рабочая версия: проверяем в игре и решённое переносим
в `roadmap.md`.

| Файл | О чём |
| --- | --- |
| `pitch.md` | основа, суть, столпы, тон, названия, открытые вопросы |
| `world.md` | три мира, три начала, вера, жрецы и колдуны, история, география, народы, календарь |
| `characters.md` | герой, Повитуха, Нетленный, стражи, домашние духи, истинные имена |
| `systems.md` | ресурсы, тело, психика, восприятие, молитва, жречество и колдовство, смерть, строительство, петли, финалы, техника |
| `bestiary.md` | нечисть, существа народов России, обереги |
| `vertical-slice.md` | состав первого играбельного среза, гипотезы и критерии их проверки |
| `roadmap.md` | порядок работы по этапам, отложенное после среза |
| `assets.md` | модели и анимации |

## Правило для всех документов

Мировоззрение игры — основа дизайна, а не его текст. Ни одна реплика не объясняет концепцию. Игрок узнаёт
мир через механику и последствия. В игре только слова её мира: Явь, Навь, Ирий, Вещество, Образ, Нить,
Зверь, Чучело, Бес, Человек, Слово.
