# Дорожная карта

Цель — vertical slice: маленькая, но настоящая игра на 2–10 игроков. Новые биомы, боссы и лодки — только после неё.

## 0. Каркас — готов

- Монорепо, общий код клиента и сервера.
- Процедурный мир из seed, стриминг чанков в Web Workers, деревья через инстансинг.
- Персонаж от третьего лица, камера, бег, прыжок, плавание.
- Авторитетный сервер, предсказание на клиенте, интерполяция чужих игроков.
- День и ночь, общие для всех.
- Анимированный герой (Quaternius, CC0): покой, ходьба, бег, спринт, прыжок, плавание.

## 1. Добыча

- Rapier: коллизии с деревьями и камнями.
- Рубка деревьев, добыча камня. Сервер хранит изменения мира по чанкам и рассылает их.
- Инвентарь, подбор предметов.
- Модели от Blender: свой персонаж на скелете UAL, дерево, камень.
- Анимации рубки и добычи.

## 2. Крафт и строительство

- Верстак, рецепты.
- Строительство деталей со snap-точками.
- Прочность конструкций: поиск по графу от земли, прочность падает с каждым звеном.
- Изменение ландшафта: мотыга, кирка.

## 3. Сохранение

- SQLite на сервере: изменения чанков, постройки, инвентари.
- Вход по имени и токену, возврат в свою точку мира.

## 4. Опасность

- Один враг (например, грейдварф), простой ИИ на сервере.
- Бой: удар, блок, выносливость.
- Смерть с выпадением инвентаря в могилу.

## Технический долг, который ждём заранее

- Бинарный протокол вместо JSON — когда в снимках появятся сотни объектов.
- LOD для дальних чанков — при росте дальности прорисовки.
- Area of interest — сервер шлёт игроку только то, что рядом с ним.
