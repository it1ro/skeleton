# Модели из Blender

## Куда класть

Экспортированные `.glb` кладутся в `packages/client/src/assets/models/`. Имя файла — это имя модели в коде:
`player.glb` загружается через `loadModel('player')`. Vite находит файлы при сборке, перезапуск не нужен.

Сейчас в игре:

- `player.glb` — герой: скелет из Meshy на костях UAL, без анимаций. Пока файла нет, вместо него рисуется капсула.
- `anims_humanoid.glb` — анимации гуманоида: только скелет и клипы. Подходят любой модели на том же скелете.

Оба файла собирает `npm run assets` из модели Meshy и пака Quaternius UAL (см. `assets-src/README.md`).

## Скелет

Стандарт проекта — скелет **Quaternius Universal Animation Library (UAL)**: 65 костей, имена как в Unreal
Mannequin (`pelvis`, `spine_01`, `Head`, `upperarm_l`, …). Анимации привязываются к костям по именам,
поэтому любая модель на этом скелете сразу получает все анимации.

Свой персонаж в Blender:

1. Импортируйте `assets-src/quaternius/Universal Animation Library[Standard]/Unreal-Godot/UAL1_Standard.glb`
   (File → Import → glTF 2.0). Его арматура — эталон.
2. Подгоните модель под позу и пропорции манекена и привяжите её к этой арматуре
   (Ctrl+P → With Automatic Weights, потом правка весов).
3. Не переименовывайте и не удаляйте кости. Длины костей можно менять: анимации берут из файла только
   повороты костей и высоту таза.

## Герой из Meshy

Модель из Meshy приходит без рига, на скелет UAL её сажает `npm run assets`:

1. Суставы манекена UAL переезжают в точки из таблицы `HERO_JOINTS` в `scripts/build-assets.ts`. Повороты
   суставов остаются прежними, поэтому клипы подходят без правок. Точки сняты с модели в T-позе вручную.
2. Каждая вершина идёт за ближайшей костью. Руки берут только вершины дальше плеча, ноги — только ниже бедра,
   поэтому рёбра не тянутся за руками, а таз — за ногой. Пальцы идут вместе с кистью.
3. Ноги у героя короче, чем у манекена, поэтому движение таза в клипах масштабируется по высоте бедра. Сборка
   печатает скорости клипов для `SPEEDS` в `animator.ts`: с короткими ногами шаг короче.
4. Металличность и карта roughness из Meshy убираются, текстура сжимается до 1024×1024 (WebP).

Новая модель из Meshy: замените `assets-src/meshy/skeleton.glb`, снимите суставы заново в `HERO_JOINTS`
(колено и локоть видны по утолщениям меша), запустите `npm run assets` и перенесите скорости в `SPEEDS`.

## Анимации

Клип в игре выбирается по имени (`packages/client/src/world/animator.ts`):

| Имя | Когда играет | Цикл |
| --- | --- | --- |
| `Idle` | стоит | да |
| `Walk` | идёт медленно, до 2,5 м/с | да |
| `Jog` | бежит, обычный ход 5 м/с | да |
| `Sprint` | бежит с Shift, 8,5 м/с | да |
| `JumpStart` | отрыв от земли | нет |
| `JumpLoop` | в воздухе | да |
| `JumpLand` | приземление на месте | нет |
| `SwimIdle` | держится на воде | да |
| `Swim` | плывёт | да |

Чтобы заменить клип своим, добавьте его в `anims_humanoid.glb` под тем же именем (или поправьте `CLIPS`
в `scripts/build-assets.ts`). Новые клипы (удар, рубка, смерть) — новые имена в `animator.ts`.

Движение в клипах — на месте (in-place), без смещения корневой кости: перемещением управляет игра.
Скорость воспроизведения подстраивается под скорость игрока, чтобы ноги не скользили.

## Правила

**Масштаб и оси.**
- Единицы — метры, 1 Blender unit = 1 м. Рост персонажа около 1,8 м.
- Перед экспортом примените трансформации: Ctrl+A → All Transforms.
- Начало координат (origin) — у ног, в центре. Модель стоит на плоскости Z = 0 в Blender.
- Персонаж смотрит вперёд в виде Front (Numpad 1), то есть вдоль −Y. Это стандарт Blender, игра разворачивает модель сама.

**Экспорт.** File → Export → glTF 2.0:
- Format: glTF Binary (`.glb`).
- Include: Selected Objects (только нужная модель).
- Transform: +Y Up включено.
- Geometry: Apply Modifiers, нормали включены. UV — только если есть текстура.
- Animation: включено, если у модели есть анимации.
- Compression (Draco) пока выключено. Сжатие включим, когда моделей станет много.

**Бюджет.** Ориентиры для слабого ноутбучного GPU:
- персонаж — до 15 000 треугольников и до 5 материалов (каждый материал — отдельный вызов отрисовки).
  Текущий герой из Meshy — около 10 400;
- дерево, камень, куст — до 1 500;
- деталь постройки (стена, пол, балка) — до 500.

**Материалы и цвет.** Стиль low-poly. Лучше цвета вершин или маленькая палитра-текстура (например, 64×64),
а не отдельная текстура на каждую модель. Principled BSDF: Roughness около 0,8–1, Metallic 0.
